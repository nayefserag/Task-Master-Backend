# 🛠️ Task Master Backend

## About

This is the backend server for the **Task Management App (Task Master)**.  
It provides a RESTful API for managing user authentication and task operations, built with **Node.js**, **Express**, and **MongoDB**.

---

## Features

- User registration and login with JWT authentication
- Secure password storage using bcryptjs
- Create, read, update, delete (CRUD) operations for tasks
- Environment-based configuration with dotenv
- CORS enabled for frontend integration

---

## 🧱 Tech Stack

- Node.js
- Express.js
- MongoDB with Mongoose
- JWT for authentication
- bcryptjs for hashing passwords
- dotenv for environment variables
- cors middleware
- nodemon for development

---
